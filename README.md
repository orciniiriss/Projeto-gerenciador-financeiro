# 🌸 Gerenciador Financeiro

Um gerenciador financeiro pessoal com uma interface delicada em tons de rosa, desenvolvido para ajudar no controle de receitas, despesas e saldo mensal.

## ✨ Funcionalidades

- Cadastro de receitas e despesas.
- Cálculo automático do saldo total.
- Resumo das receitas e despesas do mês.
- Registro de categoria, descrição, valor e data.
- Exclusão de transações.
- Armazenamento dos dados no navegador com LocalStorage.
- Interface responsiva com estilo romântico em tons de rosa.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- LocalStorage

## 🚀 Como executar

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Abra o arquivo `index.html` com a extensão Live Server ou em um navegador.

## 💾 Armazenamento

Os dados são armazenados localmente no navegador. Não há banco de dados remoto nesta versão. As transações não são sincronizadas entre dispositivos.

## 🎯 Objetivo

Projeto desenvolvido para praticar desenvolvimento web, organização de interfaces e manipulação de dados com JavaScript.
